# Play Console: Content rating (draft)

Draft answers for the **IARC content rating questionnaire** (App content → Content rating) for Live AR Fit
(`com.livear.fit`, phone and Wear OS). Owner to review; the questionnaire wording changes from time to time, so answer
each question by its meaning.

## Category

**All other app types** (not a game, not a social or communication app). Health & Fitness utility.

## Answers

| Topic | Answer | Notes |
|---|---|---|
| Violence (realistic, fantasy, blood, gore) | **No** | |
| Fear / horror content | **No** | |
| Sexual content or nudity | **No** | |
| Profanity or crude humour | **No** | |
| Drugs, alcohol or tobacco (references or use) | **No** | |
| Gambling (real or simulated) | **No** | |
| Discriminatory content | **No** | |
| User-to-user communication or interaction (chat, messaging, voice chat) | **No** | Voice commands only control the app on the user's own devices. |

| Shares personal information with third parties | **No** | No accounts; see the Data safety draft. |
| Digital purchases or in-app purchases | **No** | Free, no purchases, no ads. |
| Unrestricted internet access / web browser | **No** | The app only downloads map tiles; links to the privacy policy and map attribution open in the system browser. |

## Expected rating

The lowest rating in every region: **Everyone** (ESRB), **PEGI 3**, **USK 0**, **IARC 3+**, **ClassInd L**, with no
content descriptors. No interactive elements apply ("Users Interact", "Shares Location", "In-Game Purchases" are all
no), because nothing is shared with other users and there are no purchases.
